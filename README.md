# Фаворит-Строй — лендинг отделочной компании

Одностраничный сайт отделочной компании «Фаворит-Строй» (Калининград): ремонт квартир, отделка частных домов и коммерческих помещений.

## Стек

- Next.js 16 (App Router, Turbopack)
- React 19
- Tailwind CSS 4
- TypeScript

## Запуск

```bash
npm install
npm run dev
```

Сайт откроется на `http://localhost:3000`.

## Сборка

```bash
npm run lint
npm run build
npm start
```

## Структура

- `app/page.tsx` — весь лендинг: данные, секции, блок «Портфолио» с затемнённым коллажем, полноэкранная галерея фото, форма заявки.
- `public/works/` — 49 фотографий выполненных работ (`work-01.jpg` … `work-49.jpg`).
- `app/globals.css` — тема Tailwind, цвета, шрифты, фоновые эффекты.
- `app/layout.tsx` — шрифты и метаданные.
- `app/api/lead/route.ts` — приём заявок с формы.

## Заявки с формы

`POST /api/lead` принимает `{ name, phone }`. Если задана переменная окружения `LEAD_WEBHOOK_URL`, заявка пересылается на этот вебхук. Иначе она пишется в лог сервера.

Пример `.env.local`:

```bash
LEAD_WEBHOOK_URL=https://example.com/webhook
```

## Контакты в коде

Телефон, адрес, ссылки на мессенджеры и ИНН заданы в объекте `CONTACTS` в начале `app/page.tsx`. Текущий номер: `+7 (909) 793-30-00`.

Фотографии работ подключены через массив `WORKS` в `app/page.tsx`: чтобы заменить или добавить фото, положите файл в `public/works/` и обновите соответствующий элемент массива (`src`, `alt` и размеры).
